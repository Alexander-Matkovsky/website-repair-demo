# Mobile enquiry form repair

An interactive portfolio demo by Sasha Matkovsky. Open [the live demo](https://alexander-matkovsky.github.io/website-repair-demo/) or serve the project directory with any static file server.

- In **Before**, the contact fields extend beyond the mobile preview and the simulated form provides no submission feedback.
- In **After**, the fields stack on mobile. An invalid email gets an inline error, and a complete enquiry gets a confirmation.
- **Run checks** measures overflow in the current preview and exercises the submission logic against valid and invalid input. You can also try the form itself.

The workshop and sample data are fictional. The demo has no backend and sends no enquiries.
